# 配原图：把课件里的图表抠出来嵌进笔记

这份文档是 `SKILL.md` 第 5 步的详细做法。内容全部来自真实整理课件时踩过的坑。

## 总原则

**嵌「图里有信息」的原始页面，不嵌纯文字页面。**

判断标准：

| 该嵌 | 不该嵌 |
|---|---|
| 流程图、控制流图、状态图 | 纯文字排版的要点页 |
| 表格（尤其是测试用例表、决策表、规格表） | 只列几句话的定义页（笔记已逐句译出） |
| 曲线图、柱状图、图表 | 标题页、结束页、大纲页 |
| 地图、示意图、系统架构图 | 纯色背景 + 一两行字的过渡页 |
| **真题/考题页**（常常整页是截图） | 分栏列术语的对照表（笔记已整理成表） |
| 例题的**题面页**和**答案页** | 与别处完全重复的页面 |

一个真实例子：某课程 47 页讲义，最后只嵌了 20 张——因为剩下 27 页要么是纯文字，要么是同一批内容的动画分屏。

## 先侦察：哪一页有图

**PDF**——先抽文字层，看哪些页没文字：

```bash
python3 -I scripts/pdf_extract_text.py <src.pdf> /tmp/text.txt
```

**没有文字层的页面 = 整页是扫描/截图**，这里面最容易藏着真题。有文字层的页面再用 Read 工具**看图本身**确认是不是图表页。

**PPTX**——先列每页的配图清单：

```bash
python3 -I scripts/pptx_media.py <file.pptx> -          # 只看映射，不导出
```

输出形如 `slide 8  image13.png[41230]`。**这张清单只看「被幻灯片引用」的图片**，`ppt/media/` 里没被任何页面引用的文件会被自动排除——那些通常是模板背景和残留资源。

## 渲染

### PDF → 整页图

```bash
python3 -I scripts/pdf_render_pages.py <src.pdf> <附件目录> \
    4:第1讲-p04-边界值测试 12:第1讲-p12-贷款规格 33:第1讲-p33-决策表
```

- **一次只拆一页**（脚本内部就是 `PdfWriter().add_page()` 逐页写临时 PDF 再转图）。
- **渲染整页**，不要试图去抽 PDF 里内嵌的位图——beamer 讲义的图多半是**矢量画的**，抽出来的位图是碎的；整页渲染反而连**动画揭晓的内容**一起拿到。
- 命名格式 `<讲次>-p<PDF页码>-<中文简述>.jpg`。

### PPTX → 内嵌图

```bash
python3 -I scripts/pptx_media.py <file.pptx> <附件目录> 2,3,6,7,8,9,10,11
```

命名格式 `<讲次>-s<幻灯片号>-<中文简述>.png`。**幻灯片号就是来源出处**，别省。

### 尺寸与质量

- 长边 1400 px、JPEG 质量 82 左右，一张图 60–250 KB——够看清，又不至于把库撑爆。
- 统一放 `课程/<课程名>/附件/`（**平铺，不建子目录**），因为 Obsidian 按文件名全局解析，平铺 + 唯一文件名最省事。

## 写进笔记

```markdown
![[第1讲-p22-测试技术比较图.jpg|600]]
*原图（课件 p.22）：各种测试技术的强弱关系图。*
```

- **宽度**：小图标 `|150`–`|330`，普通图 `|520`–`|620`，很宽的图 `|620`。
- **说明格式**：`*原图（课件 p.NN）：<这张图讲了什么>。*`——斜体 + 出处，和正文区分开。
- **插在讲它的那段文字正下方**，不要攒到最后统一贴图墙。
- **一页多图**可以并列：`![[a.png|150]] ![[b.png|330]]`。
- **一组同类的图**（比如六帧走位动画、四张示例页）用表格排：

  ```markdown
  | 课件原图 | 内容 |
  |---|---|
  | ![[第5讲-s06-物流走位-1.png\|520]] | 第 1 帧：…… |
  ```

  注意表格里竖线写成 `\|`。

## 必查清单（每次配完图都过一遍）

```bash
python3 -I scripts/check_embeds.py <库路径>
```

它做三件事：

1. 列出所有 `![[...]]` 嵌入，检查**每个文件都真实存在**；
2. 检查**有没有导出后没用上的孤儿图**；
3. 顺带把 `alt` 文本缺失的嵌入列出来。

输出 `missing: 0` 且 `unused assets: []` 才算干净。（注意：表格里的 `\|` 转义会让粗糙的正则误报，脚本已经处理了这个情况。）

## 关于「我读出来的东西」——不许含糊

- 图上**有图例/标注**的，照抄，可以写进说明。
- 图上**没有图例**、靠颜色或深浅区分的，说明里必须写明：**「（以下是我的解读：深灰=…，浅灰=…）」**。
- 图上数值是**自己量/数**出来的，写「按图读数约为…」。
- 图里出现**疑似课件笔误**的，照抄，然后 `⚠️ 原文存疑`。
- 同样的诚实标准适用于**读不出来**的情况：如果某张图的曲线是幻灯片上用形状画的、文件里没有可导出的原图，就**直接告诉用户「这张导不出来」**，别去截个低清屏当原图糊弄。

## 常见的「不该导」的陷阱

| 现象 | 判断 | 处理 |
|---|---|---|
| `ppt/media/` 里有几张图，但没有任何幻灯片引用它 | 模板背景 / 残留资源 | **跳过**，并在收尾说明里提一句 |
| 图片尺寸和幻灯片尺寸完全对不上（比如 936×594 的 TIFF 出现在 4:3 幻灯片里） | 从别的文件复制残留的 | **跳过** |
| 一堆尺寸完全相同的**纯文字位图**（整页文字直接贴成图） | 不是配图，是排版偷懒 | **跳过**，笔记已经译了 |
| 同一张图在多页重复出现 | 模板/片头 | 只嵌一次，或用 `![[...]]` 复用而不重复导出 |
