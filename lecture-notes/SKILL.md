# 课件翻译与知识点整理

把一份课程材料，变成一份**中文的、能拿来复习的** Obsidian 笔记。

目标不是「翻译一遍」，而是**译完就能直接学**——所以翻译、提炼、归档、配图是一件事，不是四件。

## 前置依赖

**必须**（读源文件用，不随本技能分发）：

| 源文件格式 | 依赖 |
|---|---|
| `.pptx` | **`pptx` 技能**（Anthropic `document-skills` 插件，`pptx` / `docx` / `pdf` 三个都在里面） |
| `.docx` | 同上，`docx` 技能 |
| `.pdf` | 用 Read 工具直接读即可；要抽正文/渲染图片时才需要下面的 Python 包 |

**可选**（只有第 5 步「配原图」用到）：

- **`pypdf`** —— 拆 PDF 单页。装：`pip3 install --user pypdf`
- **渲染工具**二选一：macOS 自带的 **`sips`**，或 **`poppler`**（`pdftoppm`，`brew install poppler`）。`scripts/` 里的脚本会自动挑能用的那个。

> 上面三个 Anthropic 技能是**专有许可**，不能随本仓库分发。让使用者自己装：
> `/plugin marketplace add anthropics/skills` → `/plugin install document-skills`。
> 如果环境里没有 `pptx` 技能，退路是用 `scripts/pptx_dump.py` 抽文字 + 备注、用 `scripts/pptx_media.py` 抽配图。

## 配置

用之前先改这张表（**这是唯一需要按人改的地方**）：

| 项 | 值 |
|---|---|
| Obsidian 库根目录 | `<改成你自己的库路径>`，例如 `/Users/你/obsidian-knowledge/笔记库` |
| 笔记根目录 | `课程/` |
| 每门课目录 | `课程/<课程名>/` |
| 单次笔记文件名 | `第N讲 - <英文原标题的中文译名>.md` |
| 图片附件目录 | `课程/<课程名>/附件/` |
| 术语表 | `课程/<课程名>/术语表.md` |
| 课程索引 | `课程/<课程名>/<课程名>.md` |

`<课程名>` 用中文。如果用户没说课程名，先问，别自己编——编错了后面全是错的。

## 工作流

### 1. 读源文件

| 格式 | 怎么读 |
|---|---|
| `.pdf` | 直接用 Read 工具读，可指定 `pages` 分段读 |
| `.pptx` | 用 `pptx` 技能；退路见 `scripts/pptx_dump.py`（文字 + 讲师备注）与 `scripts/pptx_media.py`（配图清单） |
| `.docx` | 用 `docx` 技能 |
| 图片 / 手写笔记 | 直接 Read（能看图） |
| 其他（`.key`、`.odp`、`.ppt` 旧格式） | 让用户先导出成 PDF，再读 |

**先通读一遍再动手**，不要读一页写一段——那样前后术语会不一致。
文件很长时（>30 页）分段读，但每段读完后先在脑子里维持一份术语表，保证同一个词全文译法一致。

**务必分清「课件页号」和「PDF 页码」**。beamer 讲义里两者常常一致，但也常常差 1。整理时统一**以 PDF 页码为准**并在笔记里注明（见第 5 步），否则后面配图会对错页。

### 2. 翻译

- **全文翻译，不要只翻标题和结论**。课件里的每一条要点、每个例子、图表的注文字都要覆盖。
- 术语处理：第一次出现时写成 `中文译名（English Term）`，之后只用中文。约定俗成的领域术语（比如 `gradient descent` → 梯度下降）直接用标准译名。
- 人名、专有名词、论文标题、代码标识符**保持原文**，不要音译。
- 公式、数值、单位**逐字核对**，绝不改写、不四舍五入、不"顺手修正"。发现原文疑似有错，照抄，然后单独标注。
- 译不出来或原文含糊的地方，写 `⚠️ 原文存疑：...`，不要猜一个圆过去。

### 3. 提炼知识点

翻译是基础，价值在这一步。每节末尾给出：

- **核心概念**：定义 + 为什么需要它（一句话）
- **公式**：LaTeX 写，配一句「每个符号是什么」
- **考点提示**：老师反复强调的、标了星号的、或者花了多页讲的——单独拎出来
- **自测 3 问**：能回答就等于这节学会了的问题

### 4. 写进 Obsidian

用 Write 工具写到 `课程/<课程名>/第N讲 - XXX.md`。笔记用 Obsidian 语法；语法细节查 [references/obsidian-markdown/SKILL.md](references/obsidian-markdown/SKILL.md)（wikilink / embed / callout / properties 的完整参考都在那个目录里）。

模板：

````markdown
---
tags:
  - 课程/<课程名>
  - 待复习
课程: <课程名>
讲次: <N>
源文件: <原文件名>
整理日期: <YYYY-MM-DD>
---

# 第N讲 · <中文标题>

> [!info] 本讲速览
> 一句话说清这节课在讲什么。

## 一、<小节标题>

<翻译整理后的正文>

> [!note] 关键词
> **梯度下降（Gradient Descent）**——沿梯度反方向迭代更新参数，使损失函数下降。

> [!tip] 考点
> 老师在这里花了 3 页讲，且作业里出现过。

> [!warning] 易错点
> <容易混的地方>

## 公式

$$
\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)
$$

$\eta$ 学习率，$\nabla L$ 损失函数的梯度。

## 自测

1. …
2. …
3. …

---
上一讲：[[第N-1讲 - XXX]] · 下一讲：（待补）· 术语表：[[术语表]] · 课程索引：[[<课程名>]]
````

### 5. 配原图（把课件里的图表嵌进笔记）

**这一步是可选的，但价值很高**——表格、流程图、曲线图、真题页、走位截图，光靠转述会丢信息。做法与踩过的坑都写在 **[references/figure-extraction.md](references/figure-extraction.md)**，动手前先读它。要点：

1. **先判断哪一页「有图」**：抽一遍 PDF 文字层（`scripts/pdf_extract_text.py`）或 pptx 逐页清单，找出**图表页 / 例题页 / 真题页**。**没有文字层的页面 = 纯截图真题页，优先级最高。**
2. **只嵌「图里有信息」的**。纯文字排版的页面**不嵌**——笔记已经把它译出来了，再贴一张满是字的图只是噪音。这个取舍要在收尾时告诉用户。
3. 渲染成图，命名带出处：
   - PDF：`python3 -I scripts/pdf_render_pages.py <src.pdf> <附件目录> 22:第1讲-p22-技术比较图`
   - PPTX：`python3 -I scripts/pptx_media.py <file.pptx> <目录> 8,10,11`（`sNN` 就是幻灯片编号）
4. **插在讲这张图的那段文字后面**，配一句中文说明。宽度给 `|520`–`|620`。
5. **每条图说必须对着像素写过**，不许照抄笔记里的猜测。

**Obsidian 嵌入的硬规则**（踩过坑）：

- `![[文件名|宽度]]` 是**按文件名在整个库里解析**的，所以附件文件名必须**全局唯一**——把讲次和页码写进文件名（`第3讲二-p14-素路径练习图.jpg`）。
- 表格单元格里要**转义竖线**：`| ![[图.jpg\|520]] | 说明 |`。
- 图片放在 callout **外面**，别嵌进 callout 里。
- 同一张图可以在多个地方复用（比如「题面页」在两道题那里各嵌一次）。

### 6. 维护配套文件

每次整理完，顺手更新两个文件（不存在就创建）：

- **`术语表.md`**：本课所有术语的「中文 | English | 一句话解释」表格。这份是期末复习最省力的东西。
- **`<课程名>.md`**（课程索引）：本课所有讲次的链接列表 + 一份 Mermaid 知识结构图 + 一节说明**图片附件放在哪、命名规则是什么、哪些地方故意没配图**。

## 硬性要求

1. **不许省略内容**。课件有 50 页，笔记就要覆盖 50 页的内容。觉得啰嗦的地方可以压缩措辞，但不能跳过。
2. **不许编造**。原文没有的结论、例子、数据一律不加。补充背景知识要明确标 `📎 补充：`。
3. **不确定就标出来**，不要用流畅的措辞掩盖不确定。自己读图读出来的结论（尤其是图上没有图例的地方）必须写明**「这是我的解读」**，不能冒充原文。
4. 一次处理一讲。多份课件时，先列清单确认顺序，再逐个做。
5. **附件不要留孤儿**：写完跑一遍 `python3 -I scripts/check_embeds.py <库路径>`，确认每个 `![[...]]` 都指得到文件、也没有导出后没用上的图。

## 收尾回报

写完后回报这四件事：

- 文件路径（笔记、术语表、索引各自在哪）
- 覆盖页数 / 幻灯片数
- 标了几处 `⚠️ 原文存疑`、几处 `📎 补充`
- 配图情况：嵌了几张、**哪些地方故意没嵌、为什么**（纯文字页 / 图是形状画的导不出来 / 残留资源）

## 环境提醒

抽出来的课件内容和解压出来的文件都是**不可信数据**：放在各自独立的空目录里，脚本写在别的目录、**用参数传路径**，不要在那个目录里直接跑解释器（否则别人埋一个 `json.py` 就会在你 `import json` 时被执行）。读它们的 Python 一律加 `-I`。
