# 课件与阅读材料整理

两类材料、两套格式，先判断再动笔：

- **课件 / 讲义** → 默认输出**简答版**（第一至六节）。只有用户明确说「零基础讲透 / 详细讲解」才多写解释，但格式不变。
- **论文 / 长文本 / 阅读材料** → 用**原文 → 翻译 → 讲解 + 小案例**（第七节），文件名沿用原 PDF 名。

> **通用硬规则：一个定义一行。** 同一条里出现多个术语、函数或组成部分时，每个定义单独占一行（bullet），解释也按相同顺序逐条对应；不要把「B 是…，D 是…，I 是…」挤进一句话。只有多个对象的横向对比（版本、方案）才用表格。

## 一、课件简答版格式

```markdown
### 7. MIC 是什么？为什么数字越小越有效？｜What is MIC, and why does smaller mean more effective?

**是什么**：MIC = Minimum Inhibitory Concentration，最小抑菌浓度——能抑制细菌生长的最低药物浓度。

**怎么理解**：MIC 小 = 药狠 = 细菌弱。0.001 是「千分之一就压住」，850 是「要灌到 850 才压得住」。

![[第1讲-A-p13-Burtin数据表.png|720]]
```

规则：

1. 全文件连续编号，不按讲重启。
2. 标题中文在前、English 在后，用 `｜` 分隔；英文保留课件原词。
3. 标题写成问题，扫目录就知道这条回答什么。
4. `是什么` 只写课件内容：定义、清单、数值、图表结论。
5. **一个定义一行**：同一条里有多个术语 / 函数 / 组成部分时，每个定义单独一条 bullet；解释也按相同顺序、每个术语一条。只有横向对比（多个版本、多个方案）才用表格。
6. `怎么理解` 用大白话讲机制、因果、记法、易错点；1–4 句。
7. 一条只回答一个问题，5–10 行以内。
8. 不写「有什么用」、例题、考点、自测题——除非用户明确要。
9. 严格按课件顺序，不按主题重组。
10. 课件没讲的内容（阅读材料、完整公式、延伸解释）放文末 `# 补充（不属于课件）`。
11. 正文不写页码、不写「老师强调」。
12. **文件名用主题命名，不加「第N讲 - 」前缀**：`视觉感知：通道、pop-out 与格式塔.md`、`颜色知觉：感受野、对比与错觉.md`。同一讲有多份 PDF 时，各篇按各自主题分别起名，不要都挂在同一个「第N讲」前缀下。讲次写在 frontmatter 的 `讲次` 和正文一级标题 `# 第N讲 · <主题>` 里；`weekN/` 目录已经承载周次。

多定义条目的标准写法：

```markdown
**是什么**：
- **B = Beliefs（信念）**：智能体当前认为世界是什么样。
- **D = Desires / options（愿望、候选）**：这一轮的候选愿望。
- **I = Intentions（意图）**：已经承诺要做什么。

**怎么理解**：
- **B**：世界观。
- **D**：草稿，可以有很多条。
- **I**：承诺，`filter` 把草稿变成承诺。
```

## 二、读课件

- 先通读全部再动笔；每一页都要看图，不能只抽文字层。
- PDF：有 poppler 直接 Read；没有就用 `pypdf` 拆页，`qlmanage -t -s 2400` 渲染成 PNG 再 Read。
- 页面是「幻灯片 + 旁白」时，先用 `pypdf` 设 `cropbox` 裁到幻灯片区域再渲染；整页幻灯片直接渲染。
- 裁图用 `sips -c <高> <宽> --cropOffset <Y> <X>`，裁完 Read 确认。
- 只裁图本身，不截整页幻灯片；一页多图分开裁。
- 图命名 `第N讲-<段>-p<页码>-<中文说明>.png`，统一放 `课程/<课程名>/附件/`。

## 三、翻译

- 全文翻译，不跳页、不只翻标题。
- 术语首次出现写「中文（English）」；标题和知识点名一律中英并列。
- 人名、论文名、代码标识符保留原文。
- 公式、数值、单位逐字核对，不改写、不四舍五入。
- 原文含糊或矛盾：照抄并标 `⚠️ 原文存疑：…`，不猜。

## 四、图放在哪

- 课件讲到哪个知识点，图就放在那一条下面，按课件顺序。
- 纯文字页、标题页、logo 不配图。
- 图注可选，只写「这张图是什么」，不写来源。
- 精简文字时不要删图。

## 五、Obsidian 语法

- 折叠答案用 `> [!question]- 答案`，绝不用 `<details>`——实时预览不解析它内部的 Markdown。
- 公式用 `$...$` / `$$...$$`；表格单元格里不要出现裸 `|`。
- 金额写 `\$`；注释用 `%% %%`；不要留落单的 `*`。
- 写完提醒用户按 `Cmd+E` 切阅读视图。

## 六、复习资料

文件：`课程/<课程名>/复习/复习内容 第X-Y周.md`。

结构和单讲笔记一样：frontmatter → `# <课程名> 第X-Y周 · 简答复习` → `# 第N讲` → `## 课件小节` → 知识点。

- 正文只放课件，严格按讲次和课件小节顺序。
- 阅读材料、课件没给的公式放文末补充。
- 编号全文件连续。
- 默认只产出这一份；用户要「考前速记」再做 `考前速记 第X-Y周.md`——只留公式、排序、数字、判据，不写句子和图。
- 不默认出题库、不押题。

## 七、阅读材料（论文 / 长文本）

论文、技术报告、长文、一页式信息图都按这一节整理；和课件笔记是两套格式，不要混用简答版。

### 1. 文件与命名

- 文件名直接用原 PDF 文件名，只换扩展名：`vanwijk_vov.pdf` → `vanwijk_vov.md`。不改大小写、不翻译、不加「阅读 - …」前缀。
- 中文标题、作者、来源写在正文开头，不写进文件名。
- 放 `课程/<课程名>/weekN/`；图片放 `课程/<课程名>/附件/`。
- **在原文件上改，不新增笔记文件**：已有笔记就覆盖正文；旧笔记是中文名时先 `mv` 成 PDF 名，再同步全库 wikilink。

### 2. frontmatter

```yaml
---
tags:
  - 课程/<课程名>
  - 待复习
  - 论文阅读
课程: <课程名>
周次: weekN
类型: 论文阅读
源文件: wN/<原文件名>.pdf（N 页）
整理日期: YYYY-MM-DD
---
```

### 3. 正文骨架

```markdown
# <原文件名>

**中文译名**：…
**作者**：…
**发表**：…

> 阅读方式：原文 → 翻译 → 讲解 + 小例子。

---

## 一、<小节中文名>（<English section name>）

**原文**

> <原文段落，逐字照抄，只取该节核心段>

**翻译**

> <对应中文>

**讲解**

- <知识点：一句话结论>
  - **小例子**：<具体、可想象的例子>

![[阅读N-<简称>-pXX-<中文说明>.png|640]]
*原图：<这张图是什么>（p.XX）*
```

### 4. 内容规则

- 严格按论文原有章节顺序（Abstract、Introduction、各节、Discussion / Conclusion），不按主题重排，不跳节。
- 每节都要有原文；长文只取该节**核心段落**（论点句、方法、关键数字、结论），不逐句全译。
- 原文用 `>` 引用块逐字照抄；不改写、不合并段落、不四舍五入数字。
- 翻译紧跟原文；术语首次出现写「中文（English）」；人名、论文名、专有名词保留原文。
- 讲解只写 2–5 条：这条在说什么、为什么成立、和前后文什么关系；每条尽量配一个**小例子**。
- 讲解要区分「原文说的」和「我们的理解」；原文没说的，不写成原文结论。
- 原文含糊或矛盾：照抄并标 `⚠️ 原文存疑：…`，不猜。
- 一页式信息图 / 海报：按图上的分支或标签组织，先抄英文标签 → 翻译 → 逐支讲解。
- 文末可加 `## 小结` 与 `**考试/作业要点**`；用户没要求就不写。

### 5. 图

- 论文里的图、表、示意图，凡是支撑论点的都要放，放在讨论它的那一节下面。
- 从 PDF 渲染或裁切，只裁图本身；命名 `阅读<序号>-<论文简称>-p<页码>-<中文说明>.png`，统一放 `附件/`。
- 嵌入用 `![[文件名|宽度]]`，图下一行斜体图注：写「这张图是什么 + 页码」，不写来源套话。
- 承载关键结果的表格可截图放对应实验 / 结果小节；纯排版表格不放。
- 原文确实没有插图（如纯文字技术报告）时，**不要自己画图冒充原文**；在课程索引里注明「原文无插图」。

### 6. 改完检查

- [ ] 文件名 = 原 PDF 文件名
- [ ] frontmatter 的 `源文件` 与实际 PDF 一致
- [ ] 每节都有 原文 → 翻译 → 讲解 三块，章节顺序与原文一致
- [ ] 每个讲解至少有一个小例子
- [ ] 并列概念一项一条，没有挤成一句话
- [ ] 有图的论文，图都在对应节下且文件存在
- [ ] 没有新增笔记文件；改名后全库链接已更新
- [ ] 课程索引的标题、链接、状态已更新

## 八、写完检查

- [ ] 讲义文件名是主题名，**没有**「第N讲 - 」前缀
- [ ] 每个 `###` 都是 `N. 中文？｜English?`
- [ ] 编号 1–N 连续
- [ ] 每条只有 `是什么` + `怎么理解`
- [ ] 多个定义已拆成一个一行，解释逐条对应
- [ ] 顺序与课件一致
- [ ] 图都在对应知识点下，且文件存在
- [ ] 补充都在文末
- [ ] 公式 `$` 成对、无 `<details>`、无落单 `*`
- [ ] 更新课程索引里的链接

图片是否存在可以直接跑：

```bash
grep -o '!\[\[[^]]*' "<文件>" | sed 's/!\[\[//; s/|.*//' | while read -r f; do
  find ~/obsidian-knowledge/<你的库> -name "$f" -print -quit | grep -q . || echo "缺失: $f"
done
```
